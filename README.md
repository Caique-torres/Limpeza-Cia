# Limpeza & Cia

Uma aplicação web desenvolvida com HTML, CSS e JavaScript, criada para apresentar serviços de limpeza residencial, comercial e pós-obra, com foco em qualidade, confiança e praticidade no atendimento aos clientes.

## Demonstração

[ Clique aqui para acessar o Limpeza & Cia ](https://caique-torres.github.io/Limpeza-Cia/)

## Funcionalidades

- Apresentação da empresa
- Apresentação dos serviços de limpeza
- Limpeza residencial
- Limpeza comercial
- Limpeza pós-obra
- Seção sobre a empresa
- Solicitação de orçamento pelo WhatsApp
- Botões de contato integrados ao WhatsApp
- Botão flutuante do WhatsApp
- Menu responsivo para dispositivos móveis
- Layout responsivo
- Navegação entre seções da página
- Ano automático no rodapé

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts (Poppins)
- WhatsApp

## Objetivo

Este projeto foi desenvolvido para colocar em prática conhecimentos de HTML, CSS e JavaScript, trabalhando principalmente com criação de interfaces web, estilização de páginas, responsividade, navegação entre seções, manipulação do DOM e integração com o WhatsApp.
